Pedestrain Datasets

2023.05
Category: Motion Planning

Over the course of my PhD my lab has been using various pedestrian datasets to learn new behavior or analyze existing behavior. These datasets are always sent around or kept in GitHub repositories and rarely did I gather them from their initial sources. I wanted to try and track down the initial upload of each of the commonly used datasets and collect them here.

Name Author Description Links
BioTracking Georgia Tech BORG Lab Laser tracked data of individuals moving and not colliding BORG Lab
BIWI Walking Pedestrians dataset ETH Zurich CV Lab Contains the ETH and Hotel datasets Wayback Machine
UCY Dataset UCY Graphics Lab Contains Zara, Zara01, Zara02, Students003, and Arxiepiskopi UCY Graphics Lab
